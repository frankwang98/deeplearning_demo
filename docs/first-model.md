# 第一课：训练、保存并加载一个模型

目标是在 CPU 上用十分钟看清一次完整机器学习流程。程序自己生成接近 `y = 2x + 1` 的数据，因此不需要下载数据集。

```bash
python tutorials/01-first-model/train.py
```

代码分四步：生成并拆分训练/验证数据；创建只有一个权重和一个偏置的线性层；反复执行前向计算、均方误差、反向传播和参数更新；保存权重后用新模型加载并预测。训练数据会更新参数，验证数据只衡量未知样本上的表现。

正常结果中，验证损失应比初始值明显下降，权重接近 2、偏置接近 1，`x=3` 的预测接近 7。由于数据含随机噪声，数值不会完全相等。`runs/first-model/metrics.json` 保存完整历史，`model.pt` 是模型参数。

建议完成三个实验：

1. 使用 `--epochs 10`，观察训练不足的结果。
2. 使用 `--lr 0.001` 和 `--lr 0.5`，解释学习率如何影响收敛。
3. 把数据规律改成 `y = -3x + 4`，先写出你预期的权重和偏置，再运行验证。

能够回答“为什么验证阶段不调用 `backward()`”“为何保存后还要重新加载测试”，就可以进入 `pytorch_example/01-basics`。
