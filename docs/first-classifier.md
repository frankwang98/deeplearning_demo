# 第二课：从回归走到分类

第一课预测一个连续数字；第二课从三个类别中选择一个。它使用自动生成的二维数据，因此仍然无需下载数据集，而且能把模型的决策边界直接画出来。

```bash
python tutorials/02-first-classifier/train.py
python tutorials/02-first-classifier/infer.py --x 1.4 --y -0.7
```

训练程序生成三组带噪声的点，拆分训练集和验证集，只使用训练集的均值和标准差做标准化。模型输出三个原始分数，`CrossEntropyLoss` 在内部完成对数 softmax；推理时才显式调用 `softmax`，把分数变成总和为 100% 的概率。

输出目录包含：

- `classifier.pt`：权重、标准化参数、类别名和网络配置；推理所需的信息放在一起。
- `metrics.json`：每轮损失与准确率，以及最终混淆矩阵。
- `decision-boundary.svg`：背景色是模型划出的类别区域，圆点是实际样本。

混淆矩阵的行表示真实类别，列表示预测类别；对角线上的数字越大越好。准确率会把所有样本压缩成一个数字，混淆矩阵能进一步说明模型把哪个类别认成了哪个类别。

建议实验：把噪声系数从 `0.42` 改到 `0.8`；把隐藏层从 16 改成 2；删除标准化；分别观察准确率、混淆矩阵和决策边界。每次只改一个变量。
